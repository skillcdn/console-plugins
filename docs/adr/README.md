# Architecture Decision Records

One short file per decision that has lasting consequences and that a future contributor might reasonably want to undo: the shape of the repository, how a plugin is named and published and who runs its first publish, what every plugin is built against, what every plugin speaks, how a plugin is versioned, how people are told outside the console and in whose name, what a plugin owes the plugins that read it, what a request from a messenger may do while it is answered, what a plugin's pages may draw, how several Slack workspaces share one console, what a person is told of their own work and who decides it.

## Rules

- Copy [`0000-template.md`](0000-template.md) to `NNNN-short-title.md` using the next free number.
- Keep it under a page: context, decision, consequences. No essays.
- An accepted ADR is never edited, apart from its status line. To change course, write a new ADR and mark the old one `Superseded by ADR-NNNN`.
- If two changes take the same number, the one that lands second renumbers.
- A new record takes a row at the end of the index: its number, its decision and its status; the date is the record's. The index stands in sections of twenty-five rows, each under the table's header again, once it reaches the twenty-sixth.
- A record's status line and its row change together: where a later record supersedes or amends a point of it, both say which point and by which record.
- This repository is public: no business reasoning, no operations details, no comparisons with other products.
- Decisions about the contract of a plugin are made in the console's repository, and decisions about SkillCDN in the main repository, never here.
