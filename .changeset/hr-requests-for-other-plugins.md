Another plugin reads a person's requests: the api has `requests`, which answers as the query `requests` does, the caller's own unless a scope or a person is named, each with `cancellable` and `cancellation`. The query `types`, and the api's, answer each kind with `summary`, its rules in a sentence of the caller's language, the sentence `type` reads back to HR. The contract names `reason` (`optional`, `required` or `hidden`), `cancel` and `summary` among what `types` answers.
