Whoever has no language of their own, someone who never opened the console's pages, reads what the plugin writes to them, a decision or HR's task, in the workspace's language once an administrator set one on the console (`console workspace edit --language ko`), where it was English or the caller's language. Where nobody set one, nothing changes. Setup's General says which language that is, and whether anyone set it. Built for console 0.4.7 or later.
